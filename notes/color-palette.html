Choosing a Color Palette for a Portfolio

Why I picked purple, and how to keep text readable in both light and dark themes.

Start with one main color

A portfolio feels calm and professional when it has one clear accent color. I chose purple because it feels creative without being loud. Everything else is a lighter or darker version of it.

Contrast matters more than beauty

Text must be easy to read for everyone, including people with weak eyesight or a phone in bright sunlight. A common rule is a contrast ratio of at least 4.5 to 1 for normal text. Free tools such as the WebAIM Contrast Checker will measure it for you.

On Day 10 I found that white text on the lighter dark mode purple was too weak, so buttons keep the darker purple in both themes.

Use variables for every color

Because all colors are stored as CSS variables, changing the whole look of the site takes a few lines: 

:root {
  --accent: #7c3aed;
}

Want a green or blue site? Change that value and the rest follows.

Quick rules I follow

  • One main color, one soft version, and neutral text colors.
  • Never use color alone to show meaning (add text or an icon too).
  • Check both light and dark themes before publishing.
  • Test on a real phone, not only on a computer screen.
