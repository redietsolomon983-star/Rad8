Building a Dark Mode with Only CSS

A hidden checkbox and a few color variables are enough to switch a whole website between light and dark. No JavaScript needed.

The idea

A checkbox remembers one thing: on or off. CSS can read that state with the :checked selector. So the plan is simple: put a hidden checkbox at the top of the page, let a label act as the visible button, and change the colors when the box is checked.

Step 1: Use color variables

Instead of typing colors everywhere, store them once in :root and use var(--name) in the rest of the CSS. 

:root {
  --bg: #ede9fe;
  --text: #2e1065;
}

body {
  background-color: var(--bg);
  color: var(--text);
}

Step 2: Add the checkbox and the label

<input type="checkbox" id="theme-toggle" class="theme-toggle">
<label for="theme-toggle" class="theme-btn"></label>

Clicking a label toggles the checkbox it points to with its for attribute. The checkbox itself is hidden with CSS, and the label is styled as a round button.

Step 3: Swap the variables

The :has() selector lets the root element react to its own children. When the checkbox is checked, new values replace the old ones: 

:root:has(#theme-toggle:checked) {
  --bg: #1b1735;
  --text: #ede9fe;
}

Everything that uses var(--bg) or var(--text) changes automatically. Adding a transition makes the change smooth.

Limits to know about

  • The choice is not saved. Refreshing the page goes back to light mode.
  • :has() needs a modern browser (Chrome and Edge 105+, Safari 15.4+, Firefox 121+).
  • The checkbox must stay in the page, because the selector looks for it by its id.
