Portfolio Website

A responsive personal website built from scratch with pure HTML and CSS, created one day at a time with a Git commit after each step.

🌐
RoleDesign and development
Time11 days
StackHTML, CSS, Git, GitHub Pages
JavaScriptNone
Live Demo View Code

The goal

I wanted a professional place to show my skills and projects, and I wanted to prove to myself that HTML and CSS alone can do much more than people expect.

What I built

  • A responsive layout that works on phones, tablets, and computers.
  • A dark mode toggle using a hidden checkbox and CSS variables.
  • A mobile hamburger menu with no JavaScript.
  • Scroll animations using CSS animation-timeline.
  • An FAQ accordion using the built-in details element.
  • A contact form connected to Formspree.
  • Accessibility features: skip link, keyboard focus styles, and reduced motion support.

Challenges

  • No saved theme. Pure CSS cannot remember the dark mode choice after a refresh. I accepted this limit to keep the site JavaScript free.
  • Color contrast. White text on the lighter dark mode purple failed the contrast check, so I separated the button color into its own variable.
  • Browser support. Some modern selectors work only in newer browsers, so I wrote the CSS so that the site still looks fine when they are missing.

What I learned

  • How to structure CSS with variables so one change updates the whole site.
  • How Flexbox and Grid make responsive layouts simple.
  • How to write clear commits and publish with GitHub Pages.
  • That accessibility is easier when you think about it from the start.
